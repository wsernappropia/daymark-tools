Complete your first filing in about one minute.

This fictional invoice contains no personal, customer or payment data. It exists only to test Invoice Filing Assistant.

  1. Keep this instruction page open.
  2. Open Invoice Filing Assistant and turn on Enable invoice renaming.
  3. Choose File a PDF from this page. The extension will find the linked sample automatically.
  4. Confirm 2026-10-15, INV-1001 and 42.00, then file it. The current public version identifies the GitHub Pages host as the vendor.
