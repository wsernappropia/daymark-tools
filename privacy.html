Privacy policy

Daymark Tools publishes local-first browser extensions. Product data is stored in Chrome's local extension storage and is not synchronized by Daymark Tools. We do not sell user data, use it for advertising, or include third-party analytics at launch.

Invoice Filing Assistant

The extension reads user-initiated PDF download metadata and a PDF URL selected by the user. It stores a local index containing the filename, source URL, download identifier, status and timestamps. It does not upload PDF content or the local index.

ApplicationGuard

The extension stores eligible browser-form values locally so the user can preview and explicitly restore them. Passwords, payment-card fields, one-time codes, hidden fields, file contents, secrets and token-like fields are excluded. A user-requested receipt downloads a visible-tab screenshot and a JSON manifest with a SHA-256 hash. The receipt is not proof that a third-party website accepted a submission.

Licensing

When live licensing is enabled, explicit license activation sends a user-entered license key, random installation identifier and product identifier to Lemon Squeezy. Page content, documents, form values, screenshots and download history are not sent with license requests.

Retention and control

Local product data remains until the user deletes it, clears browser storage or uninstalls the extension. Chrome Web Store and Lemon Squeezy process their own service data under their respective policies.
