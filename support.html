Before reporting a problem

  1. Confirm Chrome is current.
  2. Record the extension version from chrome://extensions.
  3. Reproduce with harmless sample data when possible.
  4. Never send passwords, card data, one-time codes, private documents or real invoice content.

Safe test

Use our harmless sample invoice to verify the filing flow without exposing personal or business data.

Product limits

  • Invoice Filing Assistant saves within Chrome's Downloads directory and supported subfolders.
  • It can only find a PDF that is open directly or linked from the current page.
  • The local index is not a backup; export it if you need a portable record.
