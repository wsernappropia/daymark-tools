Before reporting a problem

  1. Confirm Chrome is current.
  2. Record the extension version from chrome://extensions.
  3. Reproduce with harmless sample data when possible.
  4. Never send passwords, card data, one-time codes, private documents or real application content.

Product limits

  • Invoice Filing Assistant saves within Chrome's Downloads directory and supported subfolders.
  • ApplicationGuard cannot restore file inputs and excludes sensitive fields.
  • Its receipt documents visible browser state; it is not proof of acceptance.

Compatibility

Confirmed breaking Chrome changes receive priority, with a target tested hotfix window of 24–48 hours.
